06 / BEFORE WE START

A few useful
answers.

What does the $350 review include?

One workflow, up to three connected tools, findings with supporting evidence, a written remediation plan and a 30-minute readout. Agree the materials, authorized testing and scope before starting. Implementation and retesting are separate.

Do we need to use X0R Core?

No. We review your existing implementation. Core is our experimental open-source engineering project and a way to show reproducible work.

Is this a real-model attack demonstration?

No. The website illustrates deterministic mock test results from a synthetic workflow. It does not run a backend or test a real model. Use the reproduction link to run the actual offline demo yourself.

Can you guarantee an agent is secure?

No. A review reports the scenarios examined, evidence observed and limits of the assessment. Operator tool grants are not end-user authorization, and this demonstration does not establish prompt-injection resistance.

Do you need production data or credentials?

Prefer staging, synthetic data and redacted materials. Agree access and testing boundaries in writing. Never send passwords, API keys or private customer records in an initial message.
