Our backbone

X0R Core — the agent backend you own.

Every build runs on the same foundation: ingestion, retrieval, tool-calling agents, quotas and evals. Open source, self-hosted, and pointed at whichever model you trust this quarter.

# run it, no API key required $ pip install -e ".[dev]" $ x0r seed workspace ws_9e83… agent agt_453d… documents 4 chunks 4 $ x0r serve INFO Uvicorn running on http://127.0.0.1:8000 INFO docs at /docs
  • Ingest anything text

    Paragraph-aware chunking, embeddings, hybrid retrieval. SQLite for a demo, Postgres for production.

  • Agents that call your tools

    A bounded tool loop with a registry you can extend. Add an order lookup in twenty lines.

  • Metered, not guessed

    API keys, workspace quotas, per-run token accounting. Quota checks happen before the model call.

  • Evals, so quality doesn't drift

    Golden-question suites with per-case scores and pass rates. Change a prompt, see the effect.

Questions

The things you're probably wondering.

If yours isn't here, ask. We answer email the same day.

Do we have to use your stack?

No. Core is our default because it removes four weeks of plumbing, but we work in your stack when that's the right call — Python, TypeScript, Go, whatever your team already runs.

Who owns the code and the data?

You do. Core is Apache-2.0 and deployed in your cloud with your keys. We don't hold your documents, and there is no per-seat toll to keep your own product running.

What if our data is a mess?

That's normal, and it's what the discovery sprint is for. We audit what exists, show you what's usable now, and tell you what would need cleaning before it's worth building on.

How fast can something be live?

A working prototype inside a week. A production pilot in about four weeks, assuming we can get access to systems and a responsible person for sign-off.

Can you work with our existing tools?

Yes — via APIs, webhooks and scheduled jobs. If a system has no API, we'll say so in the audit rather than pretend otherwise.

Will you sign an NDA?

Yes. Send yours, or use ours. We can sign before the first call.
