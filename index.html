Inspect the foundation

X0R Core.
Open code, explicit limits.

An early-stage, self-hosted Python backend for experimenting with retrieval and tool-calling agents. It is our engineering foundation, with security work developed in the open.

# local demo · mock provider · no API key $ git clone https://github.com/X0R-labs/core.git $ cd core $ python -m venv .venv $ source .venv/bin/activate $ pip install -e ".[dev]" $ x0r seed $ x0r serve Mock output demonstrates the workflow. It does not measure real-model security.
  • Available today

    Text ingestion, retrieval, workspace API keys, operator-managed tool policy, execution decision records, bounded agent loops and basic evaluation suites.

  • Security work in progress

    Resource-level user permissions, safer trace retention, connection-bound network validation and real-model adversarial evaluation remain development priorities.

  • Know the limits

    Core is experimental. A passing test suite does not certify a deployment as secure. Review the code and deployment assumptions before using sensitive data.

Before we start

A few useful answers.

Clear expectations make a small engagement useful.

Do we need to use X0R Core?

No. The service can assess your existing agent, API or cloud workflow. Core is an open-source engineering project, not a required platform.

What does the $350 review include?

One workflow with up to three connected tools, a code and architecture review, prioritized findings, a remediation plan and a 30-minute readout. Implementation and broad penetration testing are separately scoped.

Can you guarantee an agent is secure?

No. We report the controls and scenarios examined, the findings reproduced and the limits of the assessment. A review is not certification or a guarantee against all attacks.

Do you need production data or credentials?

Prefer synthetic or redacted data and a test environment. We agree access before the engagement; do not send passwords, API keys or private customer records in an initial message.

Can we keep our existing cloud and model provider?

Yes. We start with the system you already operate and scope improvements around its actual requirements.
